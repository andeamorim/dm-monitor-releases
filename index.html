How it works

  1. Install on one computerThe church computer (or a Raspberry Pi) on the same network as the console. It finds the console by itself.
  2. Share the linkMusicians open it on their phones once, install the certificate (a guided step) and add it to the home screen.
  3. Everyone mixes themselvesEach musician moves only their own mix. The tech decides who sees which channels, from the Admin.

First time opening it

  • Mac: right-click the app → Open → Open (only the first time).
  • Windows: if you see “Windows protected your PC”, click More info → Run anyway.
  • Raspberry Pi: tar xzf dm-monitor-pi-*.tar.gz && sudo ./dm-monitor/install.sh --hostname dm-monitor
  • Updates arrive by themselves: the Admin shows Update now when a new version is out.
Why the warning?

DM Monitor is free and independent, so the installers aren't signed with a paid Apple/Microsoft certificate yet. The download is the same file published here; every update is checked against its checksum before installing.
