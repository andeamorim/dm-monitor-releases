# DM Monitor — downloads

Personal monitor mixes from your phone, for Yamaha DM-series consoles.
*Compatible with Yamaha DM series — not affiliated with or endorsed by Yamaha.*

This repository only hosts the **installers**. Get the latest version from
[Releases](https://github.com/andeamorim/dm-monitor-releases/releases/latest):

| Computer | File |
|---|---|
| Mac (Apple Silicon) | `DM-Monitor-<version>-mac-arm64.dmg` |
| Mac (Intel) | `DM-Monitor-<version>-mac-x64.dmg` |
| Windows 10/11 | `DM-Monitor-Setup-<version>-win-x64.exe` |
| Raspberry Pi 4/5 (64-bit OS) | `dm-monitor-pi-<version>-arm64.tar.gz` |

Installed copies check here for new versions and offer an **Update now**
button in the Admin — you don't need to come back for updates.
